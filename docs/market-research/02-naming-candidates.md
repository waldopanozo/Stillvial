## Criteria

- Memorable, short brand pronounceable in English and Spanish.
- Suggests calm, order, and flow; primary name does not depend on saturated keywords `Water Sort`, `Color Sort`, `Liquid Sort`, `Bottle Game`, or `Tube Puzzle`.
- Leaves room for the differentiators: local daily, patterns beyond color, offline and no tracking.
- Reasonable `kebab-case` form for repo and package.
- No obvious clash in an initial GitHub / Play / F-Droid / web / DNS review.

## Method and limits

Exact or near searches on [GitHub](https://github.com/search?type=repositories), [Google Play](https://play.google.com/store/search?c=apps), [F-Droid](https://search.f-droid.org/), and the web. The table includes a homogeneous Google `"<name>" game` search as web evidence of possible game collisions. GitHub API repo-name counts are a signal only, not a trademark reservation. DNS A for `.com` / `.dev` is a light signal.

These checks reduce discovery risk; they are not a legal trademark search and do not prove domain availability (a domain may be registered without an A record). Before shipping, review game classes in target jurisdictions and register/confirm the chosen domain.

## Shortlist (4)

### Pausa Pour

- Joins an intentional daily pause with the core pour gesture; soft in both languages; not a generic genre label.
- Residual risk: `pausa` is common; domain/mark availability needs jurisdiction checks before launch.
- ES: «Ordena el color, a tu propio ritmo.»
- EN: “Sort color at your own pace.”

### Stillvial

- Suggests calm vessels and a serene experience; allows patterns as visual identity without “water sort”.
- Residual risk: GitHub returned zero repos on recheck, but that is not a legal clearance; “vial” also overlaps alchemy-game semantics.
- ES: «Un pequeño ritual de orden, cada día.»
- EN: “A small ritual of order, every day.”

### Mosaic Tide

- Links patterns, layers, and flow with imagery more distinctive than tube vocabulary; fits daily + pattern accessibility.
- Residual risk: conceptual/search nearness to *Mosaic Match*; always use the full compound, never “Mosaic” alone.
- ES: «Patrones que fluyen hacia la calma.»
- EN: “Patterns that flow into calm.”

### Flowmori

- Compact, evocative: flow + organic hint; works for an offline brand centered on a calm routine.
- Residual risk: orthographic nearness to Flowmory and inevitable *Flow Free* association. Deeper legal review if prioritized.
- ES: «Fluye, ordena, respira.»
- EN: “Flow, sort, breathe.”
